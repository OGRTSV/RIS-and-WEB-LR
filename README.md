# ИС «Запись на консультацию»

Курс Б1.В.ДЭ.01.02.02 · КГЭУ · семестр 1 · 2026/2027

## О проекте

Веб-система для управления записью студентов на консультации преподавателей кафедры ЦСМ. Система автоматизирует процесс: студент создаёт заявку, заведующий кафедрой назначает преподавателя-исполнителя, преподаватель подтверждает и проводит консультацию. Каждая запись имеет жизненный цикл со статусами (поступила → подтверждена → проведена / отменена) и хранится в единой базе данных, заменяя разрозненные договорённости в мессенджерах и бумажных блокнотах.
