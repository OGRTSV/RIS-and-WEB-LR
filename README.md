# ИС «Учёт и оценка рисков сервисных учётных записей AD»

Курс Б1.В.ДЭ.01.02.02 · КГЭУ · семестр 1 · 2026/2027

## О проекте

Веб-система для инвентаризации сервисных учётных записей Active Directory, оценки связанных с ними рисков информационной безопасности и контроля устранения выявленных нарушений. Система ведёт единый реестр сервисных учётных записей, автоматически рассчитывает уровень риска по заданным факторам (отсутствие владельца, бессрочный пароль, избыточные привилегии и др.) и формирует задачи для системных администраторов с полным жизненным циклом: создание → назначение → выполнение → закрытие.
